# 出发了么 · 使用说明

一个单文件移动端网页（`index.html`），双击即可用浏览器打开，无需构建工具。
下面四条是后续最常改的地方。

---

## 1. 怎么替换地图 API Key

打开 `index.html`，搜索 **`AMAP_KEY`**（在「数据区」末尾）：

```js
const AMAP_KEY      = '2afbbfa869c025e099693057f16b45b0';      // 已填好：高德 Web 端(JS API) Key
const AMAP_SECURITY = 'c4b16d3d112cb7d72a36dd6a7e31da03';      // 已填好：安全密钥 securityJsCode
const MAP_TIMEOUT   = 6000;   // 6 秒没渲染完就自动退回手绘图
```

> ⚠️ **改这两个值时千万别删掉英文单引号。** 密钥必须写在引号里面，写成
> `const AMAP_SECURITY = xxxx '';` 这种样子会产生语法错误，**整页 JS 都会失效、页面全白**。
> 这是最容易踩的一个坑。

**三重兜底（不会白屏）**
1. 页面加载时先画手绘 SVG 路线图，永远有内容；
2. 高德只在切到「这样玩」这一屏时才初始化（隐藏容器里初始化会拿到 0 宽高，渲染出来就是空白）；
3. 加载失败 / 6 秒超时 → 自动退回手绘图；成功后地图下方会出现「⇄ 换成手绘示意图」按钮，随时手动切。

**申请步骤**
1. 打开 [高德开放平台控制台](https://console.amap.com/dev/key/app) → 用支付宝/手机号登录 → 创建应用。
2. 在应用下点「添加 Key」→ 服务平台选 **Web 端 (JS API)**。
3. 安全密钥 `securityJsCode` 在 Key 的详情里，一并填到 `AMAP_SECURITY`。
4. 把两个值填回去，**保存刷新页面**，地图区域右上角会显示「高德地图」。

**说明**
- 没填 Key 时不会白屏：会自动降级成手绘 SVG 路线图（城市按经纬度比例定位，虚线还有流动动画），功能完全可用。
- JS API 2.0 要求必须配 `securityJsCode`，否则会报 `INVALID_USER_SCODE`。
- 如果想换更贴合页面配色（浅绿低饱和）的底图：控制台 → **自定义地图样式** → 调好颜色后发布，会得到一个 `mapStyle` 串，替换代码里的 `'amap://styles/whitesmoke'` 即可。

## 2. 怎么把城市网图换成自己的照片

搜索 **`CITY_IMAGES`**（在数据区开头附近）：

```js
const CITY_IMAGES = {
  '北京': '',
  '福州': 'https://你的图床/fuzhou.jpg',   // ← 填上 URL 就会自动用这张图
  '泉州': '',
  '厦门': ''
};
```

- 留空 `''` → 显示「渐变 + SVG 城市剪影」占位图，每城配色不同，不会难看。
- 填了 URL → 自动切成正片，`loading="lazy"` 懒加载；**万一图片挂了会自动回落占位图**，不会出现裂图。
- 建议尺寸：宽 ≥ 750px 的横向图，长宽比约 3:2，尽量避开纯白天空（卡底部有深绿渐变遮罩，深色/暖调照片效果最好）。
- 图床推荐：微信朋友圈/公众号素材上传、阿里云 OSS、或者 GitHub 仓库里直接放图用 raw 链接。

## 3. 怎么修改清单和行程数据

所有内容都在 `<script>` 顶部的**数据区**，四个变量对应四个区块：

| 变量 | 作用 | 对应页面位置 |
|---|---|---|
| `TRIP` | 路线、天数、**出发日期**、**出行人数**、备注 | 顶部标签 + Tab1 行程信息卡 |
| `CITY_IMAGES` | 城市配图 URL | 顶部横向卡片组 |
| `CITIES` | 城市名称、一句话标签、经纬度、景点、餐厅、酒店 | 顶部卡片 + Tab2 地图与城市卡 |
| `LINES` | 城市间交通方式、耗时、详情文案 | Tab2 地图上的圆形徽章气泡 |
| `CHECKLIST` | 准备清单的分组与条目 | Tab1 |
| `DAYS` | 每天的上/下午/晚上行程 + 吃什么 | Tab2 行程一览 + Tab3 时间轴 |

**几个省事的设计**
- **景点打点靠坐标**：`CITIES[].sights` 里只要写了 `lng` / `lat`，这个景点就会在地图上出现一个小绿点，点它能**唤起高德地图**；没写坐标就只出现在城市卡片里。住宿同理，写 `hotelLL:[lng,lat]`。
  - 坐标不准？打开[高德坐标拾取器](https://lbs.amap.com/tools/picker)搜景点名，抄回 lng/lat 替换即可。
- **唤起高德**用的是官方 URI API（`uri.amap.com/marker`）：装了高德 App 会直接唤起 App，没装就打开网页版高德。
- **找餐厅**：手机上点店名会弹一个底部面板，三个出口，只要装了一个就能走通：

  | 选项 | 走哪条路 | 说明 |
  |---|---|---|
  | 打开大众点评 App | `dianping://searchshoplist?keyword=店名` | ⚠️ 不要用 `shopinfo`，那个只接受店铺 id，传关键词无效 |
  | 在高德地图里搜这家店 | `uri.amap.com/search?keyword=&city=` | 点评 App 唤起失败时的兜底，和「看地图」同机制 |

  - 选「打开 App」后 1.5 秒页面没被切走（= 没装点评 App），会**自动改用高德地图搜索**。
  - ⚠️ **唤起 App 必须在真正的浏览器里打开本页才有效**（Safari / Chrome）。
    在微信内置浏览器里会被拦住，点右上角 **··· → 用浏览器打开** 即可。
  - 延迟兜底一律用 `location.href` 而不是 `window.open`——后者在 setTimeout 里会被手机浏览器当弹窗拦掉。
  - 关掉面板改 `SHOP_SHEET = false`，恢复成直接打开点评网页版。
  - ⚠️ **大众点评的网页版在手机浏览器上不可靠**（实测会 302 到 `verify.meituan.com` 的风控页，也可能报服务端 404）。这是点评侧的限制，页面改不了。所以「高德地图」才是找店铺的可靠路径。
- **日期不用手算**：改 `TRIP.start` 这一处，六天的日期会自动顺推。想在某天写死，就在那个 day 对象里加 `date: '10 月 3 日'`。
- **清单条目加备注**：写成 `'小标题|灰色小字'` 就行，例如 `'身份证（成人）|带了记得拍照备份'`。
- **餐厅/酒店自动变成胶囊按钮**：写在 `eats` 或 `CITIES[].eats` / `hotel` 里，会渲染成可点的点评搜索按钮，不用手写链接。
- **删掉某个区块**：把对应的数组留空 `[]`，页面会自动隐藏这个区块，不会留一个空标题在那儿。
- **`AMAP_KEY` / `AMAP_SECURITY`** 见第 1 条。

## 4. 怎么部署到网上

### 方案 A · GitHub Pages（免费、稳定）
1. 在 GitHub 新建仓库（Public），把 `index.html` 拖进去（**文件名必须是 `index.html`**）。
2. 仓库 → **Settings → Pages → Build and deployment → Source 选 `Deploy from branch`**，分支选 `main`，目录选 `/ (root)`，Save。
3. 等 1–2 分钟，访问 `https://你的用户名.github.io/仓库名/`。
4. 之后每次改完直接在网页上传新版 `index.html`，一分钟左右自动生效。

### 方案 B · Vercel（不用写命令行也可以）
1. 打开 [vercel.com](https://vercel.com) → GitHub 登录 → **Add New → Project** → 导入刚才那个仓库 → Deploy。
2. 不想用 Git 也可以：本地建个文件夹，里面只放 `index.html`，然后电脑装 Vercel CLI 上传：
   ```bash
   npm i -g vercel
   cd 文件夹目录
   vercel --prod
   ```
3. 部署完会给你一个 `xxx.vercel.app` 的网址，可以直接丢到微信里打开。

### 部署后的小提示
- 用手机发给旅伴时，直接在微信里打开链接就行；iOS Safari 点「分享 → 添加到主屏幕」，用起来跟 App 一样。
- 勾选进度存在**各自手机的浏览器本地**里，换设备不会同步（这是刻意的，避免旅伴互相清掉对方的勾）。
- 如果用浏览器内打开时发现地图片区空白，检查一下你是否处在能访问 `webapi.amap.com` 的网络环境；不影响其余功能。
